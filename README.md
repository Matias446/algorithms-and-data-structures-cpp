# Algorithms and Data Structures – C++

## Description
This repository contains implementations developed for an Algorithms and Data Structures course, including multiple algorithmic problem solutions and custom data structure implementations written in **C++**.

## Contents
- Algorithmic problem solutions (10 exercises)
- Custom Abstract Data Types implementations
- Graph-related structures and priority queues
- Hash maps and heap-based structures
- Input/output test cases for validation

## Technologies
- C++
- Git

## Purpose
Academic project focused on implementing classical algorithms, data structures and problem-solving techniques, emphasizing efficiency and algorithmic complexity analysis.
